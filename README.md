# 🎨 AI Image Generator Using OpenAI API

## 📌 Overview

The **AI Image Generator** is an AI-powered application that generates images from text prompts using OpenAI's API. It allows users to describe an idea, concept, or scene in natural language and transform their descriptions into AI-generated visual content.

This project demonstrates the practical application of **Generative AI and API integration** to build an intelligent image-generation solution.

## ✨ Features

- **Text-to-Image Generation:** Generate images from user-provided text prompts.
- **OpenAI API Integration:** Connects to OpenAI's API to generate images using supported image-generation models.
- **Creative Image Generation:** Transform ideas and descriptions into visual content.
- **Prompt-Based Input:** Generate different images by changing the text prompt.
- **AI-Powered Creativity:** Explore the use of Generative AI for digital art and visual content creation.

## ⚙️ How It Works

1. The user enters a text prompt describing the desired image.
2. The application sends the prompt to OpenAI's API.
3. The API processes the prompt using a supported image-generation model.
4. The generated image is returned to the application.
5. The user can view the generated image.
